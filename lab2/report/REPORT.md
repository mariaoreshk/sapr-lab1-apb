# Материалы отчёта: ЛР2, вариант 6

## Цель
Разработать на SystemVerilog APB-устройство для сложения и вычитания
двух 32-битных чисел, проверить моделированием и средствами Quartus.

## Задание
Вариант 6: сложение и вычитание двух 32-битных чисел с доступом к
регистрам operand1, operand2, control, result. Правила коммитов аналогичны ЛР1.
Источник: «Задание_лр2 М3О-409Б (1).docx».

## Реализация
Карта регистров и команды приведены в ../README.md.
В always_comb формируются ответы APB и мультиплексор данных чтения.
PREADY подтверждает access-фазу без ожидания. PSLVERR сообщает о неверном
адресе, записи в результат или недопустимой команде. Полный адрес проверяется,
поэтому обращения вне устройства и невыровненные адреса не создают псевдонимов.
В always_ff регистры сбрасываются и изменяются на положительном фронте pclk.
Неблокирующие присваивания описывают синхронную память.
Операторы + и - выполняют арифметику; 32-битный result отбрасывает перенос.
После изменения операндов result хранит прежнее значение до новой команды.
Результат можно трактовать как беззнаковое число либо дополнительный код;
отдельного флага переполнения задание не требует.

Стенд tb_alu содержит master-модель в задаче transfer: setup, затем access,
проверка ответа до фронта завершения. Следующая setup-фаза может начинаться
без снятия psel. Входы меняются на спаде, что исключает гонку с логикой slave.
Задача calculate записывает операнды, проверяет чтение, запускает команду и
сравнивает result с эталоном. При несовпадении используется $fatal.
Есть общий тайм-аут. Тестовые данные воспроизводимы: xorshift с фиксированным seed.

setup-фаза, сохранение результата до команды и сброс во время access.

## Повторный запуск
В PowerShell, из корня C:\altera\lab1:
1. cd lab2\scripts
2. & C:\altera\13.0sp1\modelsim_ase\win32aloem\vsim.exe -c -do run.do -l simulation.log
3. cd ..\fpga
4. & C:\altera\13.0sp1\quartus\bin\quartus_sh.exe --flow compile lab2

Для просмотра диаграмм откройте ModelSim из lab2\scripts, выполните:
do run.do (пакетная проверка завершается автоматически).
Для интерактивного просмотра: vlib work; vlog -sv ../rtl/apb_alu_slave.sv ../tb/tb_alu.sv;
vsim work.tb_alu; add wave -r sim:/tb_alu/*; run 29630 ns.
При просмотре сохранённого файла: vsim -view vsim.wlf.
