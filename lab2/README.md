# Лабораторная работа №2 — вариант 6

ЛР1 сохранена в исходных каталогах и в теге v1.0. ЛР2 развивается в ветке lab2-variant6.

Устройство выполняет сложение и вычитание 32-битных чисел по модулю 2^32.
Базовый адрес: 0x70000000. Все обращения — 32-битные, выровненные.

| Смещение | Регистр | Доступ | Назначение |
|---|---|---|---|
| 0x00 | operand1 | rw | первый операнд |
| 0x04 | operand2 | rw | второй операнд |
| 0x08 | control | rw | 0 — сложение, 1 — вычитание |
| 0x0c | result | ro | результат последней команды |

Запись в control выполняет операцию на том же фронте завершения APB.
Изменение операндов само по себе не меняет result. После сброса все регистры равны 0.
Зарезервированные биты control должны быть нулевыми. Ошибочные адреса,
невыровненные обращения, запись в result и неверные команды завершаются
с PSLVERR без изменения регистров. Slave не добавляет такты ожидания.
Сброс синхронный, активный низкий. PREADY активен только в access при снятом сбросе.

Структура: rtl — синтезируемый slave; tb — тестовые стенды; scripts — запуск ModelSim; fpga — проект Quartus. Из каталога scripts выполните vsim -c -do run.do для полной проверки или vsim -c -do run_master.do для проверки с apb_master из ЛР1.

## Кодовое покрытие

Из корня репозитория запустите .\lab2\scripts\run_coverage.ps1 (нужны Python 3 и ModelSim в PATH; пути можно указать параметрами -Python и -Vsim). Скрипт добавляет метки в отдельную копию RTL и запускает оба тестовых стенда в ModelSim. Он считает исходы if и варианты case только для apb_alu_slave. Нативная лицензия msimcoverage не нужна. Логи остаются во временном каталоге.

С мастером ЛР1 покрыто 10 из 17 ветвей. После функционального стенда покрыто 16 из 17 (94,12 %). Непокрытый default в case записи недостижим через APB: pslverr блокирует неизвестные адреса и запись в result до входа в case. Покрытие выражений и переключений этим скриптом не измеряется.
